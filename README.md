# Video Games sales-Analysis using Python
Analysed a gamers dataset to understand the performance of different genres in different regions and gave recommendations on how to improve sales in regions exhibiting low sales. 

## BUSINESS PROBLEM.


A gaming company wants to understand:
1.What genres generate the most revenue.
2.Which regions drives sales.
3.Which publishers dominate the gaming industry.
4. How the Industry has evolved over time.
